RICHFIELD SMART CAMPUS RESOURCE BOOKING SYSTEM

Richfield Smart Campus Resource Booking System is a dekstop-based python application designed to streamline, track, and manage institutional resource allocations across multiple phisical campuses. Built using Tkinter for a strucrured graphical user interface (GUI) and powered by an embedded SQLite3 relational database engine, the platform enforces strict role based authorization scopes and campus-specific booking policies.

Python Libraries used to build Richfield Smart Campus Resource Booking System
* Python
* Tkinter
* SQLite3
* Datetime

Richfield Smart Campus Resource Booking System has three main workspaces:
* Lecturer Workspace
* Campus Administrator Workspace
* System Operator Workspace

Lecturer Workspace:
This is where the lecturer can request resource reservations, view history schoduling timeliones, and securely drop existing personal calendar allocations

Campus Administrator Workspace:
This is where the administrator can complete create, read, update, delete (CRUD) data control over campus asset inventory, including hardware and facilities.

System Operator Workspace:
The system ioperator can utalize cross campus business intelligence panel calculating structural metrics, transaction quantities, and average allocations windows.
